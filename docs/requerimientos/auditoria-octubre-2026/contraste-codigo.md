## Como se lee el veredicto

- CONSERVAR: la pieza ya hace lo que el caso le pide.
- CAMBIAR: la pieza es el lugar del caso, y hoy no lo cierra.
- NO USAR PARA ESTE CASO: la pieza es de otro flujo. Usarla acreditaria un caso que no es.

Un caso cumplido exige que el codigo de hoy cierre lo que la sala pidio. Una pieza que conserva un trozo no tapa el borde que otra pieza deja abierto.
