# Comentarios: caracteres

Al redactar un comentario en Trello, un texto de pantalla en el front, o cualquier otro comentario (codigo, docs, respuestas), no uses estos caracteres. Reemplazalos al escribir.

| No usar | Usar |
|---|---|
| `—` (raya larga) | `-` |
| `→` (flecha) | `>` |

Ejemplo: `Cartola > contabilizar - reunion 28/08`, no `Cartola → contabilizar — reunión 28/08`.
